# 플레이어별 같은 팀 빈도 탭 설계

## 목표

`/stats`에 기준 플레이어가 다른 멤버와 같은 팀이었던 횟수와 비율을 매치 단위로 보여주는 `팀 동료` 탭을 추가한다.

같은 팀 비율은 다음과 같이 계산한다.

`같은 팀 매치 수 / 두 플레이어가 함께 참가한 전체 매치 수 × 100`

## 화면

- 기존 통계 탭 목록에 `팀 동료` 탭을 추가한다.
- 기존 `PlayerSidebar`에서 기준 플레이어를 선택한다.
- 표에는 `다른 멤버`, `같은 팀`, `함께 참가`, `같은 팀 비율`을 표시한다.
- 같은 팀 비율 내림차순, 같은 비율이면 같은 팀 횟수 내림차순으로 정렬한다.
- 기존 연도 필터를 그대로 적용한다.
- 결과가 없으면 빈 상태를, 요청 실패 시 오류 메시지를 표시한다.

## 집계 규칙

- `Match` 한 건을 한 번으로 센다.
- 두 플레이어가 같은 매치에 참가하면 `함께 참가`를 1 증가시킨다.
- 두 플레이어가 같은 `MatchTeam`에 속하면 `같은 팀`도 1 증가시킨다.
- 매치 안의 개별 게임과 게임 중 팀 변경은 집계하지 않는다.
- 기준 플레이어 자신은 결과에서 제외한다.
- 선택한 연도가 있으면 한국 시간 기준 해당 연도의 매치만 집계한다.
- 비율은 화면 표시용으로 소수점 첫째 자리까지 반올림한다.

## 구조와 데이터 흐름

1. 기존 팀 편성 API는 선택 연도의 모든 플레이어 쌍에 대해 동시 참가와 같은 팀 횟수를 이미 제공한다.
2. 새 탭 컴포넌트는 기존 선택 플레이어 컨텍스트와 `useTeamComposerData`를 사용한다.
3. 선택 플레이어가 포함된 쌍만 추려 상대 플레이어 정보와 같은 팀 횟수, 함께 참가한 횟수, 같은 팀 비율을 표로 렌더링한다.
4. 기존 탭 해시 동기화, 연도 필터, 플레이어 사이드바를 재사용한다.

새 데이터베이스 테이블, 마이그레이션, 외부 의존성은 추가하지 않는다.

## 오류 처리

- 선택된 플레이어가 없거나 해당 연도의 짝 데이터가 없으면 빈 상태를 표시한다.
- 기존 팀 편성 데이터 요청 실패는 탭 안에서 오류 상태로 표시한다.

## 검증

- 순수 집계 함수 단위 테스트로 같은 팀, 상대 팀, 여러 매치, 기준 플레이어 제외, 정렬과 비율을 확인한다.
- 기존 팀 편성 API와 연도 필터 연결을 타입 검사와 기존 테스트로 검증한다.
- `/stats`에서 탭 선택, 플레이어 변경, 연도 변경, 모바일 가로 스크롤을 수동 확인한다.

## 제외 범위

- 게임 단위 집계
- 승률 또는 듀오 성과와의 결합
- 최소 매치 수 필터와 페이지네이션
- 전체 조합 매트릭스
